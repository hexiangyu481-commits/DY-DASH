# 嵌入式迁移边界

目标硬件为 STM32H743 与 800×480 横屏，当前仓库仍是浏览器 UI 原型，没有固件、通信驱动或硬件性能结论。

## 可复用逻辑

`script.js` 的 `CONFIG`、`METRICS` 和 `WarningRules` 分离阈值、单位与警告判定。`Drivetrain` 和 `Simulator` 是测试数据源，不是车辆数据采集层。`Renderer` 与 `DashController` 管理浏览器显示与输入。

未来接入真实数据时，将模拟数据源替换为统一传感器样本适配器，保留字段语义：RPM、速度、档位、油温、油压、水温、电压、进气温、节气门。真实档位不得直接沿用模拟器的 5MT 换挡状态机。

## 必须新增与验证

- 为每个字段记录单位、采样时间、有效性及过期状态；缺失油压不能显示成正常数据。
- 核实具体车辆的传动比、轮胎尺寸、ECU、档位信息来源及各项信号可用性。
- 保护规则需要按发动机工况标定；当前固定油压阈值仅供演示，不能直接用作实车保护。
- 浏览器依赖的 DOM、SVG、CSS 与 `requestAnimationFrame` 需要迁移到嵌入式图形和调度实现；并非直接编译即可运行。
- 独立验证采样延迟、渲染帧率、触摸响应、强提示可读性和故障优先级。

## 画面比例

默认展示坐标为 960×540（16:9）；硬件预览为 960×576（5:3），等比例缩放对应 800×480。硬件移植应使用目标屏幕原生尺寸并重新检查字号，不以网页缩放结果代替硬件验收。
